ChatGPT Business Account 💼

Set up a new business trial

Create a NEW Account

Activate Business Trial

4

Pick the Business Plan

OpenCode Integration 🔗

Open-source coding agent for terminal / IDE / desktop

🤖 What is OpenCode?

OpenCode is an open-source coding agent that works in your terminal, IDE, or desktop. Connect it to your ChatGPT Business account for full model access.

1

Download & Install

Download from opencode.ai and install.

2

Connect OpenAI

Open OpenCode → Settings → Providers → OpenAI → Connect.

3

Login

A browser window opens — log in with your ChatGPT Business account. Done.

✅

You now have access to all current OpenAI models inside OpenCode.

📊 Track Your Usage

Monitor usage at:

URL https://chatgpt.com/codex/cloud/settings/analytics#usage

03

OmniRoute ⚡

Auto-switch accounts when one hits its limit

🔄 What is OmniRoute?

OmniRoute lets you keep multiple accounts in one place and auto-switch between them when one hits its limit. Works with OpenCode and Claude Code.

Repo: github.com/diegosouzapw/OmniRoute

1

Install Node.js v22.22.2

Download from nodejs.org/en/download

2

Install OmniRoute

Terminal npm install -g omniroute@3.5.3
3

Set a Password

Windows (CMD) set INITIAL_PASSWORD=YOUR_PASSWORD
macOS / Linux export INITIAL_PASSWORD=YOUR_PASSWORD
4

Run OmniRoute

Terminal omniroute

The OmniRoute dashboard opens locally in your browser. Log in with the password from step 3.

5

Dashboard Setup

  • Providers → OpenAI Codex → connect your OpenAI account
  • API Manager → create an API key (copy it)
  • Endpoints → copy the localhost URL
6

Connect to OpenCode

Back in OpenCode → Settings → Providers → Custom:

  • Paste the localhost URL as the endpoint
  • Paste the API key
  • Add the models you want (copy from the OmniRoute panel)
