💬 Wait, Telegram Has Unlimited Storage?

Yes! Telegram gives every user unlimited cloud storage for free. You can upload files up to 4 GB each — photos, videos, documents, anything. The problem? Telegram's app isn't built to manage large file collections.

That's where Telegram Drive comes in. It's a free, open-source desktop app that turns your Telegram account into a proper cloud drive — like Google Drive, but with no storage limits and no monthly fees.

02

Get Your Telegram API Keys 🔑

You'll need these to connect the app to your account

1

Open my.telegram.org

Go to my.telegram.org in your browser and log in with your phone number.

2

Click "API Development Tools"

After logging in, you'll see a page with a few options. Click on API development tools.

3

Fill the Form

Enter any app name (e.g. "My Drive") and a short description. The platform can be Desktop. Then click Create.

📝

You can write anything here — it doesn't affect the app. Just fill in the required fields and submit.

4

Copy Your API ID & API Hash

You'll now see your API ID (a number) and API Hash (a long code). Copy both — you'll paste them into Telegram Drive next.

⚠️

Keep these private. Never share your API ID and Hash with anyone. They give access to your Telegram account.

03

Set Up Telegram Drive 🚀

Connect the app to your Telegram account

1

Install & Open the App

Run the installer you downloaded earlier. Once it's installed, open Telegram Drive.

2

Enter Your API Credentials

The app will ask for your API ID and API Hash. Paste the ones you copied from my.telegram.org.

3

Log In with Your Phone Number

Enter your Telegram phone number. You'll get a verification code on your Telegram app — type it in.

4

You're In! 🎉

That's it. You now have a full cloud drive powered by Telegram. Start uploading files, creating folders, and streaming videos.

✅

Your files are stored in your Telegram account (as "Saved Messages" or private channels). You can access them from any device with Telegram too.

🧠 How Does It Actually Work?

Here's the simple version:

  • Telegram gives you unlimited cloud storage — every account gets it for free.
  • Each file can be up to 4 GB in size.
  • Telegram Drive uses your account's "Saved Messages" and private channels as storage folders.
  • The app connects to Telegram's servers using the official API — so it's fast, secure, and reliable.
  • Your files are encrypted by Telegram and stored on their servers worldwide.

Think of it like this: Telegram is the storage, and Telegram Drive is the file manager that makes it easy to use.

💡 Pro Tips

  • Create separate folders for photos, videos, documents, etc. — keeps things clean.
  • Use drag & drop to upload multiple files at once.
  • Stream before downloading — save disk space by watching videos directly in the app.
  • Works alongside Telegram — your regular Telegram chats are not affected at all.
  • Back up important files — since Telegram syncs across devices, your files are always accessible.

Common Questions

Quick answers to things people usually ask

Is it really free?

Yes, 100% free. Telegram Drive is open-source and Telegram's storage is free. No hidden charges.

Is it safe?

Yes. The app runs on your computer and connects directly to Telegram. No data goes through any third-party server. Your API keys stay local on your machine.

Will my Telegram chats be affected?

No. Telegram Drive uses "Saved Messages" and private channels — your personal and group chats stay completely separate.

What file types can I upload?

Anything — photos, videos, PDFs, ZIPs, code, music. Any file type works, as long as each file is under 4 GB.

Does it work on Mac with Apple Silicon (M1/M2/M3)?

Yes! There are separate downloads for Intel and Apple Silicon Macs. Pick the one that matches your chip.
